# Machine-Learning-Project-Assignment

# Customer Churn Prediction & Lifetime Value (CLV) Estimator

A comprehensive **Machine Learning** project that performs **Customer Churn Classification** and **Customer Lifetime Value (CLV) Regression** using **all major supervised learning algorithms** and ensemble techniques.

---

## 📋 Project Overview

This project implements **both Classification and Regression** tasks on the **Telco Customer Churn Dataset**. It demonstrates the application of **15+ machine learning algorithms**, detailed comparative analysis, visualizations, and a fully functional **Web Application** for predictions.

### 🎯 Objectives
- Predict whether a customer will **churn** (Yes/No)
- Estimate **Customer Lifetime Value (CLV)**
- Compare performance of all major ML algorithms
- Deploy the best model as a **Web Application**

---

## 🛠 Algorithms Implemented

### Classification Models (Churn Prediction)
- Logistic Regression

- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Gradient Boosting
- XGBoost
- Bagging
- AdaBoost (Boosting)

### Regression Models (CLV Prediction)

- Decision Tree Regressor
